# Carpeta de Imágenes de Proyectos - Equinox

¡Hola! Aquí puedes subir las imágenes reales de tu taller para que se muestren automáticamente en la galería del sitio web.

## Nombres de Archivos Soportados

Para que las imágenes se enlacen con sus respectivos proyectos de forma automática, súbelas a esta carpeta (`/public/proyectos/`) con los siguientes nombres exactos. Nuestro cargador inteligente acepta formatos de imagen tanto `.png` como `.jpg` o `.jpeg`:

1. **Batería de Reactores de 5.000L**
   - Nombre: `reactor-5000l.png` o `reactor-5000l.jpg` o `reactor-5000l.jpeg`

2. **Skid Modular de Filtración Tangencial**
   - Nombre: `skid-filtracion.png` o `skid-filtracion.jpg` o `skid-filtracion.jpeg`

3. **Depósitos de Almacenamiento Estéril**
   - Nombre: `depositos-calorifugados.png` o `depositos-calorifugados.jpg` o `depositos-calorifugados.jpeg`

4. **Línea de Tubería Sanitaria (Piping CIP)**
   - Nombre: `piping-sanitario.png` o `piping-sanitario.jpg` o `piping-sanitario.jpeg`

5. **Intercambiador de Calor de Haz Tubular**
   - Nombre: `intercambiador-tubular.png` o `intercambiador-tubular.jpg` o `intercambiador-tubular.jpeg`

6. **Decantadores Gravitacionales EDAR**
   - Nombre: `decantador-inox.png` o `decantador-inox.jpg` o `decantador-inox.jpeg`

---

*Nota: Si no subes ninguna imagen real para un proyecto determinado, la página web cargará automáticamente una preciosa imagen técnica de stock industrial de alta definición (de Unsplash) para garantizar que el diseño web siempre se vea impecable.*
